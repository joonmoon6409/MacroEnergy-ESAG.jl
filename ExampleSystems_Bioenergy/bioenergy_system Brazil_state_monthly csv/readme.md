# 28 States in Brazil with Monthly Time-Step Basis, Complete Bioenergy System Example

This example presents a nationwide model covering all 28 states in Brazil, representing the complete Bioenergy System and all its pathways, including selected manures, crops, and residues. It utilizes CSV-based asset data to demonstrate a comprehensive bioenergy model for Brazil, incorporating the harvest seasonality of sugarcane, corn, and soybean. Additional details will be provided in future updates.
