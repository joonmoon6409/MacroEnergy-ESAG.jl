# 공개데이터 기반 한국 전력계통 모델 생성 결과

**오직 공개 데이터만으로** 한국 전력계통을 재구성한 CSV 모델입니다. 컬럼(1행 헤더) 스키마는
PSS/E raw 포맷과 호환되도록 구성해, 범용 조류계산 도구(pandapower 등)로 그대로 읽을 수 있습니다.

> 📊 **주요 참고자료 — EPSIS 통계를 광범위하게 참고**
> 모델 규모·부하 수준·**권역별 부하 점유율**·**발전 연료믹스(용량·발전량)** 는 **EPSIS(전력통계정보시스템)·KPX**의
> 공개 통계(2024)에 맞춰 보정했습니다. 설비 위치·선로 경로는 OpenStreetMap/OpenInfraMap, 발전 호기는
> EPSIS/KPX·발전사 공개자료, 권역 점유율은 EG-TIPS/EPSIS 시도별 소비량을 사용했습니다(상세 출처는 §2).

> ⚠️ **설계 원칙 — 규모를 모른다고 가정**
> 모델의 크기와 각 요소의 다중도(변압기 뱅크 수, 회선 수, 부하 수, 부하 레벨, 분로 크기)는
> **오직 (a) 실제 존재하는 공개 설비 목록과 (b) 한국 계통의 표준 공학 관행**으로만 결정했습니다.
> 실제 계통 정보와 크게 다를 수 있습니다(예: 변압기는 "모든 변전소 N-1 → 뱅크 2대" 규칙의 결과).

- 생성 스크립트: [`../codes/modeling/build_model.py`](../codes/modeling/build_model.py) (결정론적, `seed=20240607`)
- 입력 공개데이터: [`../references/osm_subs.json`](../references/osm_subs.json) (OpenStreetMap/OpenInfraMap 변전소), 코드 내 발전설비·부하·FACTS 테이블
- 재현: `python codes/modeling/build_model.py`

> **조류계산 강건화(공개 KPG-193 참고)**: ① 제주 지역발전(남제주·제주LNG·한림복합·제주내연,
> 공개 실플랜트)+**제주-본토 HVDC 연계** 추가 → 제주 전압 0.78→0.998pu. ② **154kV 메시 보강**(각 154모선
> 2소스 인입+2인접)으로 **전부하 100% 수렴**(이전 ≤90%). ③ **FACTS 모델링**(공개 정격
> ±MVAR 전압제어, q-limit). ④ **고덕(345kV) 노드 신설**(OSM 누락분)+**북당진-고덕 HVDC ±500kV 3GW**
> 등가 연계+삼성평택 부하+고덕 STATCOM → 수도권 전압 보강. ⑤ **154/22.9 OLTC 부하시 탭조정**(주변압기
> 2차 22.9kV 모선을 ~1.0pu로 자동조정, ±12% 범위 1%스텝) + **N-1 firm 뱅크 증설**(154/23 용량 58→81% EPSIS)
> → 배전모선 전압 0.905→1.0. ⑥ **MST 백본으로 선로·회선긍장 동시 정합** — EPSIS 긍장은 회선긍장(C-km)(실계통
> 765 선로 ~580km vs 1,024가 결정적). 345·154 백본을 **지리적 MST(Prim)+루프+2회선**(154는 345/154 주입점 뿌리
> multi-source MST)으로 재구성(초기 345·765) → **회선긍장(circuit) 108%(765)** 정합. **345·154는 item ⑩-⑪에서 실제 OSM 선로로 교체(106/97%·AC총계 100%)**(HVDC 등가선은 별도 분류;
> 기존 메시의 route 과다 345 174%·154 132% 해소). ⑦ **실제 345 간선 회랑(CORR345 21개) + 비실재 연계 prune(EXCLUDE345 16쌍)** —
> 좌표-MST가 못 잡는 실제 345 간선(호남·중부 7개 + 영남 9개 + 수도권 3개 + 충청 2개; 영남엔 신규 스위칭노드 **북대구** 포함)을 **공개 계통도(KIEE 2019 Fig.1)** 정독 +
> 사용자 교차확인으로 명시 추가하고, 그림에 없는 좌표-MST 비실재 연계 16쌍(신경산-고령·신마산-창원·신녹산-서부산·서울T1-영등포·신옥천-청원 등)은 제거. 늘어난 실제
> 회선긍장은 루프 단일회선화(`KM_N345_LOOP_DBLKM` 40→0)로 상쇄해 EPSIS 107% 유지. **HVDC는 운영 준공분만**: 제주-본토 3링크(해남#1·진도#2·**완도#3 2024-11**)+북당진-고덕;
> 계획설비 동해안-신가평(2029)·서해안(2030)·강원허브·신화천은 제외(웹검증).
> ⑧ **제주 154 내부 환상망(JEJU154)** — 지리적 154 MST가 제주를 제외(HVDC로만 급전)해 제주 154 변전소가 발전 인출선만 있고 환상망 누락→대부분 고립이던 것을, **공개 제주 계통도(ef2012_70, KEPCO, Fig.5)** 의 해안 환상망 13구간(23회선·346 c-km) 추가(신제주-동제주-조천-성산-표선-한라-신서귀-남제주화력-안덕-한림 환상 + 산지·중앙 교차) → **제주 32모선 전부 급전·전압 0.995~1.004**.
> 조류해 V평균 **1.00**·V최저 **0.950**·손실 **1.96 GW**(부하의 2.3%)·<0.95 모선 0·**연결성분 1개**(전 모선 급전; KPG-193 0.988/0.952 정합). ⑬ **발전 연료믹스 정합**(금번 item 26) — 누락 LNG 15개소(+~8 GW) 추가로 **LNG 42.4 GW 용량 1위**(석탄 39.2 추월; 용량% 가스29·석탄27·신재생22·원자력18=EPSIS 정합), 석탄 CF 0.90→0.65로 발전량% 원자력28≈석탄28≈가스25, **enforce_q_lims 첨두 수렴 달성**(수도권 로컬 LNG↑+metro 345 무효보강; 손실 2.27→1.96 GW=발전이 수도권 부하 근처로 이동). ⑫ **shunt 위치·갯수 점검** — 921→**311**(→item 26 347): 345캡 全버스→PF식별 표적, 배전 PF캡은 큰 부하 변전소만(임계 110MW), 소형은 부하 역률 내재화(물리 중립). 세팅(MVAr) 비공개=자유지만 위치·갯수는 공개관행 정합. ⑦ **345/154 OLTC**(자기변압기 ULTC로 154측 ~1.0 조정). **발전기 무효한계 honor**(첨두선 relax). ⑨ **OSM 완전성 확인·실변전소 복원·765 병합·제주 HVDC 실착지** — OSM=OpenInfraMap 동일데이터(0diff) 확인; 좌표인식 디둡(154 694→697); 신울산 765 중복병합(9→8=EPSIS); 제주-본토 HVDC 실 변환소(해남/진도/완도) 착지(321 c-km, 98%). ⑩ **154 백본을 실제 OSM 선로로 교체** — `osm_lines_154.json`을 `build_osm_topology.py` watershed+스냅핑복구로 변전소-변전소 회선 추적→`osm_154_edges.json`(689쌍+갭필130), 154 회선긍장 99%. ⑪ **345 백본도 실제 OSM 선로로 교체 + 약전압 shunt 보강**(금번) — `osm_345_edges.json`(117쌍+갭필19); OSM가 사용자 CORR345 **8회랑 확인·EXCLUDE345 7 prune 검증**(`KM_345_OSM=0`에 수동 MST+CORR345 폴백 보존). feeder-circuit 추정으로 345 **106%**·AC총계 **100%**. 순수 OSM의 충청·호남 fringe 약전압(세종·신강진=실 방사상)은 **345-버스 스위치드 캡**으로 보강 → V최저 **0.950**·<0.95 0(발전기가 강모선 흡수). *토폴로지 인플레 없이 전압만 해결 — shunt 세팅 비공개라 정당.* 검증: KPG-193(arXiv:2411.14756) 공개값과 비교.

## 4. 핵심 한계 (반드시 인지)

1. **조류해(潮流解) 아님** — `vm_pu`·`va_deg`는 명목값. pandapower/PSS/E에서 조류계산 필요.
2. **선로 위상학은 일부 추정** — 765 회랑과 345 주요 간선(CORR345 21개: 호남·중부 7 + 영남 9 + 수도권 3 + 충청 2, 북대구 신규노드 포함)은 공개 계통도(KIEE Fig.1)에서 읽은 실제 회랑이라 실계통과 일치하고 그림에 없는 좌표-MST 연계 16쌍은 제거(EXCLUDE345). 나머지 345·154 메시는 좌표 MST 추정이라 실제 한전 회선구성과 다를 수 있음.
3. **전기정수는 전형값** — 한전은 회선별 임피던스 비공개. KPG-193 ㎞당 표준치 사용.
4. **ID/모선번호·설비 ID는 합성** — 실제 한전 번호체계와 무관(무작위).
5. **좌표는 OSM 크라우드소싱** — 한전 공식 좌표 아님, ±수백 m.
6. **시점 혼재** — 가동중 설비 기준(고리1·2, 월성1, 보령1·2 등 폐지분 제외). 2024년 기준.
7. **값 형식은 PSS/E raw 규약을 따름** — `bus.type`=PQ/PV/REF, `in_service`·`is_slack`=1/0 정수, `shunt.kind`=SWITCHED/FIXED, `facts.mode`=정수 1. 본 모델은 전 설비 운전중(`in_service`=1)입니다.
8. **신재생 반영(공간분포 = KEA 2023 최신 시도별)** — 태양광 29GW·풍력 2.1GW(EPSIS 계통연계 ~2024)를 **KEA 2023 보급통계 시도별 분포**로 154kV에 PQ 분산(290존). 개별 사이트 접속점은 비공개라 권역 집계 근사. 스냅샷 하계오후(태양광 CF0.45·풍력 CF0.15, 13.4GW must-run). KEA 보급통계 총량(32GW, 옥상 포함)이 아닌 EPSIS 계통연계 총량을 쓴 것은 계량부하와의 이중계상 방지.
